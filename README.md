# West End Meat

Quote, order list, invoice and expense app for West End Meat catering. Build a per-person (or by-the-pound) quote, get the shopping list for the event, send quotes and invoices as PDFs, and track income and expenses by job and by year.

Live app: https://jimmolt.github.io/West-End-Meat/

Single HTML file. Data is saved in the browser on the device.
